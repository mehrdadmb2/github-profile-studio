Does the scan require a GitHub token?
No. It calls the public GitHub REST API without authentication. The unauthenticated API has a relatively low hourly rate limit, so very large scans may need to be retried later or configured with a token outside this public static app.

        
Will the exported README need this website?
No. It is normal Markdown plus local SVG assets. Upload README.md and the included assets folder to a repository named exactly like your GitHub username.

        
Does the automatic workflow overwrite my README?
No. The included optional workflow only refreshes the generated contribution SVG. It deliberately does not create, replace or edit README.md.

        
Where is my draft stored?
In this browser's local storage. Export JSON to back it up or move it to another device. A share link contains only basic layout settings, not your full profile text.
