FAQ
Designed to stay useful.
Does the username scanner use real GitHub data?
Yes. Profile and repository metadata come directly from GitHub's public REST API. Contribution history is loaded from a public contribution-data service because GitHub's normal REST profile endpoint does not expose the calendar directly.
Can the exported README work without ProfileForge?
Yes. The README is ordinary Markdown and the companion SVG assets are local files. Upload them into your profile repository.
Can I make the profile auto-refresh?
Yes. The repository includes an optional GitHub Actions workflow and a Node script for scheduled asset refreshes.
Are these GitSkins files?
No. This is an independent clean-room implementation inspired by public interaction patterns and publicly documented theme/template concepts. No proprietary source code or private assets are included.



ProfileForge is an independent, clean-room implementation inspired by the public interaction patterns of modern GitHub README studios.
